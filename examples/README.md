# 会诊案例存档

以下为真实会诊运行记录（平台互联模式，全部为真实 AIP 委派，本地任务账本与 AMP 日志可逐条复核）。每个案例包含用户提问原文与《会诊意见书》交付内容。

| 案例 | 用户画像 | 展示重点 |
|---|---|---|
| [高校毕业生租房补贴](case-租房补贴-个人场景.md) | 个人 | 系统性纠错民间传言；**击破本方专家的错误推算**（"已超期4个月"被推翻）；根本文件404时诚实降级+核实路径 |
| [国考报考资格](case-国考报考-个人场景.md) | 个人 | **指出提问自身的时间矛盾**（先修前提再作答）；击破"约75%/80%"伪精度结论，以条件—后果对照表替代；识别网传文件版本标错 |
| [考研报考](case-考研报考-个人场景.md) | 个人 | 同词跨体系概念辨析（招生"应届"≠就业"应届"）；**拒绝错误归因**（通读原文否认惯用错引）；证据分级诚实（第三方转载明示） |
| [研发费用加计扣除·两轮会诊](case-加计扣除-两轮会诊实录.md) | 企业 | **从平台外部智能体成功取回法条原文**（跨队数据交换实证）；纠正过时政策比例认知；两轮迭代会诊 |

三个个人场景案例为同一用户画像（2024届本科毕业生）在租房、考公、考研三个人生节点、四个政策体系（人社/公务员/教育/税务）的连续会诊——展示系统对同一用户的持续服务能力。

案例运行方式：在梧桐平台对话入口向"政策会诊主持"发起提问，主持澄清要素后按三阶段（独立作答→交叉质询→仲裁）编排六位成员，条文核查官可委派本队检索官联网取证、必要时经发现服务委派平台其他队伍智能体——所有外部调用在意见书末尾逐条披露，本地任务账本（方向/对端AIC/状态/时间）可逐条复核。
