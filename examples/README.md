# 会诊案例存档

以下为真实会诊运行记录（平台互联模式，全部为真实 AIP 委派，本地任务账本与 AMP 日志可逐条复核）。每个案例包含用户提问原文与《会诊意见书》交付内容，用于直观展示三阶段协作、联网取证与跨队智能体互联。

| 案例 | 类型 | 展示重点 |
|---|---|---|
| [研发费用加计扣除](case-加计扣除-跨队互联与自我纠错.md) | 跨队互联 · 自我纠错 | 纠正过时政策认知；跨队智能体调用（成功取回法条/零命中）全披露；检索受限时置信度自动降级不拍板 |
| [高新技术企业认定](case-高企认定-原文明确型.md) | 原文明确型 | 检索官联网抓政府网站原文（单轮18次搜索+3次抓取）；交叉质询纠错与撤回留痕；八项条件逐条档位归属 |

两类典型形态：政策原文**公开可查**时满篇条款引用+出处（原文明确型）；原文**不可得或制度存疑**时如实输出待核实并给核实路径（待核实型，案例整理中）。两种形态出自同一套会诊机制，取决于现实中文件是否存在——系统不做无依据推断。
